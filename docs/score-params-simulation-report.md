# 评分参数重构：50 季对照模拟报告

创建日期：2026-11-11

> 这是 [`rating-and-records-redesign.md`](rating-and-records-redesign.md) 第 6.6 节要求的阶段 D 前置材料。
> 报告本身不改任何产品代码。是否实施阶段 D、以及采用哪组参数，由作者决定。

## 0. 结论

**不建议按方案原文实施阶段 D。** 方案提议的三项改动里，只有第一项（收敛后卫 `scale`）
有数据支持；另外两项（`leagueStrength` 提权、`availability` 降权）没有证据支持，
而且三项叠加会把四位置 P90 极差从 **1.6 推到 7.9**，同时让叙事阈值产出**腰斩**。

建议改为单项改动：**后卫 `scale` 1.85 → 1.60**，其余参数保持不变。

| 指标 | 现状 | 方案原文 | 建议（仅 DF 1.60） |
| --- | --- | --- | --- |
| 四位置 P90 极差 | 1.6 | 7.9 | 3.2 |
| 四位置中位数极差 | 5.2 | 5.4 | 4.8 |
| 四位置 P10 极差 | 8.1 | 2.8 | 6.4 |
| 金球奖后卫占比 | 40%（20/50） | 0%（0/50） | 20%（10/50） |
| 金球奖历史结果变动 | — | 62% | 22% |
| 叙事 `>=70` 新星池 | 256 | 169（−34%） | 249（−3%） |
| 叙事 `>=85` 精英池 | 165 | 64（−61%） | 113（−32%） |

## 1. 方法

**一次模拟，多组参数。** 模拟是最贵的部分，重算只是算术，所以所有候选参数都作用在同一批
球员-赛季上。这样把「公式影响」与「模拟漂移」彻底分开，候选之间也可直接比较。

- 矩阵：5 个种子 × 10 季 = **50 季**，与方案 6.6 要求的规模一致。
- 样本：**25,916** 个球员-赛季，其中 `confidence >= 0.5` 的可信样本 **19,161** 个。
- 无效分数：**0**（无 NaN / Infinity / 越界）。
- 口径与 `scripts/audit-player-performance.ts` 一致：分布只统计可信样本。

参数映射是精确的：方案只改每位置的 `scale`，不改 `median`，因此

```text
qualityNew = 50 + (qualityOld - 50) × (scaleNew / scaleOld)
```

`leagueStrength` 不能按比例缩放——引擎会按出场分钟在分段之间加权混合，跨两张
级别表无法还原，所以改由分段重算。

**已知偏差**：`positionQuality` 在进入本脚本之前已被 clamp 到 [0, 100]，落在边界上的样本
无法精确映射。本次 236 个（**0.91%**），偏差方向已知——边界样本会**低估**候选分数。

**未建模的部分**：公式变了之后，引擎自身的转会决策与身价评估也会随之不同。本报告测的是
公式的分布影响，不是它会引发的二阶世界。

## 2. 逐位置分布

可信样本，P10 / 中位数 / P90：

| 候选 | GK | DF | MF | FW |
| --- | --- | --- | --- | --- |
| 现状 | 56.8 / 64.5 / 75.8 | 48.7 / 60.5 / 75.0 | 54.9 / 64.5 / 75.0 | 54.9 / 65.7 / 76.6 |
| 方案原文 | 52.0 / 62.5 / 77.5 | 51.1 / 59.7 / 69.7 | 53.9 / 62.6 / 72.4 | 53.0 / 65.1 / 77.6 |
| 仅 DF 1.60 | 56.8 / 64.5 / 75.8 | 50.4 / 60.9 / 73.4 | 54.9 / 64.5 / 75.0 | 54.9 / 65.7 / 76.6 |
| 仅 DF 1.40 | 56.8 / 64.5 / 75.8 | 51.9 / 61.1 / 72.2 | 54.9 / 64.5 / 75.0 | 54.9 / 65.7 / 76.6 |

读法：

- **现状的后卫是「方差最大」而不是「分数最高」**。后卫中位数 60.5 是四个位置里最低的，
  但 P90 75.0 与其他人持平，P10 48.7 又显著更低。也就是说后卫分布被拉长了，
  真正的异常发生在 P90 之外的极上尾——那正是金球奖只看最顶端时会出问题的地方。
- 收敛 `scale` 会把后卫分布从**两端向中间压**：P10 抬升、P90 下降，中位数几乎不动。
  这是「降低方差」的应有效果，无法只压一端。
- 方案原文里 GK 与 FW 的 P90 反而**上升**（75.8→77.5、76.6→77.6），因为它们的 `scale` 被调高了；
  后卫 P90 同时降到 69.7。两头一起用力，P90 极差因此爆开。

## 3. 金球奖得主分布

50 季，用真实 `ballonDorScore` 乘子排名：

| 候选 | GK | DF | MF | FW | 冠军队球员 | 平均联赛排名 | 与现状不同 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 现状 | 1 | **20** | 18 | 11 | 34 | 1.66 | — |
| 方案原文 | 11 | 0 | 11 | 28 | 39 | 1.48 | 31（62%） |
| 仅 DF 1.60 | 2 | 10 | 23 | 15 | 35 | 1.54 | 11（22%） |
| 仅 DF 1.40 | 3 | 2 | 27 | 18 | 37 | 1.44 | 19（38%） |
| 仅 DF 1.25 | 3 | 1 | 27 | 19 | 36 | 1.56 | 19（38%） |

读法：

- **现状的异常是结构性的**：后卫中位数最低，却拿走 40% 的金球奖，前锋只有 22%。
  这与 S6 试玩里「市值 €16M 的保级队后卫夺金球」的观感一致。
- 仅 DF 1.60 把后卫占比降到 20%，同时把前锋抬到 30%，是所有候选里**最均衡**的一组
  （GK 4% / DF 20% / MF 46% / FW 30%）。
- DF 1.40 及更激进会把后卫清零，但代价是中场独占 54%，只是把失衡从后卫挪到中场。
- 方案原文让门将拿到 22%，这是 `scale` 0.83→1.00 造成的：门将 P90 抬到 77.5，
  与前锋并列最高，门将因此进入最顶端竞争。

**一个副产物**：全部候选、全部 50 季的金球得主都来自顶级联赛（次级 0、三级 0）。
这说明金球奖里 `×0.90 / ×0.78` 的级别折扣目前**完全没有起作用**——低级别球员本来就进不了最顶端。
该折扣是为「世界级奖项」定性的，不是当前的实际调节器。

## 4. 叙事阈值敏感度

对应 `src/engine/observation/narrative-world-scan.ts` 的硬编码阈值，统计触发池规模：

| 候选 | `>=70` 新星（≤22 岁 + 可信度≥0.25） | `>=76` 老将（≥31 岁） | `>=85` 精英 | 位置领跑者 `>=85` | `>=75` 转会回升（≥450 分钟） |
| --- | --- | --- | --- | --- | --- |
| 现状 | 256 | 488 | 165 | 99 | 2091 |
| 方案原文 | 169 | 262 | 64 | 43 | 1252 |
| 仅 DF 1.60 | 249 | 437 | 113 | 79 | 1882 |
| 仅 DF 1.40 | 239 | 401 | 93 | 63 | 1729 |
| 仅 DF 1.25 | 233 | 369 | 89 | 59 | 1602 |

读法：

- 方案原文会让叙事产出**腰斩**：新星池 −34%、老将池 −46%、精英池 −61%、转会回升门槛 −40%。
  方案 6.7 的验收里写着「无叙事稀疏或泛滥」，这一条不通过。
- 仅 DF 1.60 对新星、老将、转会三条线的影响都在 10% 以内，只有精英池下降 32%——
  而「85+ 应当稀缺」本来就是设计意图，这一下降方向是对的。

**报告口径修正**：方案 6.6 写的是「四个硬编码阈值（70 / 76 / 85 / confidence 0.25）」，
但代码里还有第五个阈值 **75**（`narrative-world-scan.ts:820` 的转会后回升门槛），
本报告一并纳入统计。

## 5. 星味验收回归

[`star-player-presence-plan.md`](star-player-presence-plan.md) 已验收的口径是
「30 种子 × 20 季，四位置中位数最大差 **1.9**、P90 最大差 **2.0**」。

**该基线在本次 50 季样本上无法复现**：现状公式在这里测得中位数极差 **5.2**、P90 极差 **1.6**。
P90 与基线接近（1.6 vs 2.0），中位数差了近 3 倍。

可能是样本量差异（50 季 vs 600 季），也可能是该基线在 `PLAYER_SCORE_VERSION` 之前测得。
无论是哪种，**都不能拿候选参数去和 1.9 / 2.0 比**——那会把样本差异当成公式影响。
本报告因此只做同数据对比：候选 vs 现状。

| 候选 | P10 极差 | 中位数极差 | P90 极差 |
| --- | --- | --- | --- |
| 现状 | 8.1 | 5.2 | **1.6** |
| 方案原文 | 2.8 | 5.4 | **7.9** |
| 仅 DF 1.60 | 6.4 | 4.8 | **3.2** |
| 仅 DF 1.40 | 4.9 | 4.6 | **4.4** |
| 仅 DF 1.25 | 3.9 | 4.4 | **5.3** |

**这是本次模拟最重要的单条结论**：现状公式在 P90 上的四位置对齐是 **1.6**，已经接近完美。
任何压缩后卫方差的改动都必然让后卫 P90 下降，从而推高这条极差——这是数学上的必然，
不是调参失误。方案原文把它推到 7.9（5 倍），是因为同时又抬高了 GK/FW 两端。

**建议**：在正式实施前，先用 `pnpm audit:player-performance`（30 种子 × 20 季）
把现状基线重测一遍，确认 1.9 / 2.0 是否仍然成立。若重测后现状中位数极差确实在 5 左右，
则说明星味文档的验收数字已经过期，应当先更新验收标准再谈参数。

## 6. 建议方案

```ts
// src/engine/players/player-performance.ts
const POSITION_QUALITY_CALIBRATION = {
  GK: { median: 52.7, scale: 0.83 },   // 不变
  DF: { median: 52.1, scale: 1.60 },   // 1.85 → 1.60
  MF: { median: 48.5, scale: 1.42 },   // 不变
  FW: { median: 50.9, scale: 1.14 },   // 不变
};

// 权重与联赛强度映射保持不变：
// adjustedPositionQuality × 0.70 + availabilityScore × 0.20 + leagueStrength × 0.10
```

理由：

1. **缺陷范围比方案假设的窄**。观察到的唯一异常是后卫极上尾过厚，这只由后卫 `scale` 决定。
2. `leagueStrength` 提权没有证据支持。金球得主 100% 来自顶级联赛，级别区分在奖项层面
   本来就不构成问题；而它会整体压低次级联赛球员的评分。
3. `availability` 降权**方向可能对**（轮换球员少受一层惩罚），但本次模拟只测到它会让
   四个位置的中位数**一律下移约 2 分**并压低全部叙事阈值。方案称其为「双重惩罚」，
   本报告没有测到「去掉后轮换球员相对受益」的证据——这条需要单独设计实验，不要顺手改。
4. 改动面小：只动一个常量，历史金球结果变动 22%，远低于方案原文的 62%。

## 7. 本报告未覆盖

- **二阶效应**。公式影响转会与身价，模拟里没有让新公式反过来驱动世界。需要跑两次完整模拟
  （旧参数一次、新参数一次）才能看到，这是本报告做不到的。
- **600 季口径复核**。星味基线 1.9 / 2.0 在 50 季上无法复现，原因未定位。
- **轮换球员专项**。`availability` 降权是否真的改善轮换球员的相对评价，没有测。
- **玩家可见面**。位置榜、球员页、世界焦点、MOTM 占比的变化没有统计。

## 8. 复现

```sh
npx tsx scripts/audit-score-params.ts                 # 5 种子 × 10 季 = 50 季
SCORE_PARAM_SEEDS=2 SCORE_PARAM_SEASONS=3 npx tsx scripts/audit-score-params.ts   # 快跑
```

候选参数在 `scripts/audit-score-params.ts` 的 `CANDIDATES` 常量里，增删候选只需改这一处。
脚本只读产品代码，不修改任何参数。
