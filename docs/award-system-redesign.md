# 评奖系统重设计（第一期：算法 + 奖项风向）

状态：实施中。范围仅限评奖算法与「奖项风向」面板；球员中心整体重构留到第二期。

## 为什么要改

v4.62.0 的评奖在一次实测里暴露了三类问题：一个联赛杯 + 超级杯双冠王，五项个人奖加最佳教练无一入选，而射手王却出自该队。

1. **球队成就几乎不进个人奖。** 只有金球奖有团队乘子；最佳后卫 / 最佳门将 / 最佳新星 / 赛季综合表现 / 射手王全部是纯个人分。
2. **杯赛荣誉只认洲际杯。** `season-end.ts` 传给评奖的 `continentalCupWinners` 只有大陆杯 / 南方杯 / 东方杯，而这三个杯 `firstSeason: 5, interval: 6`，六年才一届。联赛杯和超级杯冠军对个人评分贡献为零。
3. **同一个"最佳"有三份互不一致的实现。** 射手王新闻与金靴奖用 `playerStats` + 严格 `>`（先到先得），赛季回顾的射手王卡片用 `playerStatsHistory` + 进球→助攻→出场。进球并列时三者必然分歧。
4. **层级口径互相矛盾。** `seasonScore` 里联赛强度只占 10% 权重、跨度 10 分（顶级 100 / 甲级 95 / 乙级 90），实际只值 1 分；金球再乘 ×0.90 / ×0.78 构成双重折扣；金靴完全无系数；最佳后卫 / 门将硬性锁死顶级联赛。同一个乙级球星被三套规则分别对待。
5. **最佳教练惩罚强队。** `expectedPos = round(16 × (1 - (expectation - 1) / 4))`，expectation = 5 的三支豪门 expectedPos = 0，夺冠超额值为 −1，数学上永远拿不到该奖。
6. **前锋和中场没有位置奖。** 只有最佳后卫 / 最佳门将，中场球员在评奖体系里没有任何位置路径。

## 不可预判如何做到（不加随机）

评审结论：**奖项本身保持 100% 确定性**，不引入任何抽签。理由：

- 产品契约要求叙事只解释模拟事实，不改写结果；评奖属于模拟结果。
- RNG 流是承重墙。杯赛阶段 1 给超级杯加 pots 分档后，一次洗牌变四次，整个赛季构建的随机流错位，20 个候选种子里没有一个还能满足开局断言，推荐种子被迫从 20260709 换到 20260722。在颁奖时插一次抽签会让这类审计全部作废。

不可预判由三个诚实机制叠加产生：

1. **热度公式与评奖公式不同。** 风向卡用 `buzz = 0.5×赛季分 + 0.3×近 5 场状态 + 0.2×球队近 6 场势头`；评奖用全季聚合 + 最终联赛排名。两者本就不是一回事。
2. **阈值带代替名次。** 相邻候选 buzz 分差超过 `BAND_WIDTH` 才另起一档，档内按球队名排序而非分数。卡片只显示「最被看好 / 有力竞争 / 黑马」三档，不显示任何数字与名次。这既诚实（他们确实接近），又消掉了"第一就是冠军"的读法。
3. **最大变数本来就未揭晓。** 金球乘子里权重最高的是最终联赛排名（冠军 ×1.18 / 前四 ×1.08 / 后四 ×0.94）。第 16 轮时排名仍可大洗牌——即使把真实评分原样贴出来也预测不了第 30 轮。

跑火车的情况不隐藏：唯一领跑者且与次席差距超过 `RUNAWAY_GAP` 时，卡头标记「一人领跑」。那种情况玩家本来也算得出来，藏它没有意义。

## 系数表

全部集中在 `src/engine/awards/award-weights.ts`，便于审计与调参。

### 层级系数

| 层级 | 通用 | 金靴 | 新星 |
| --- | --- | --- | --- |
| 顶级 | 1.00 | 1.00 | 1.00 |
| 甲级 | 0.90 | 0.90 | 0.95 |
| 乙级 | 0.80 | 0.80 | 0.90 |

新星刻意用更轻的折扣：它是低级别联赛冒头球员的指定通道。

**已知问题：赛程长度不等。** 顶级 30 轮，甲级 / 乙级各 14 轮。金靴按原始进球乘系数时，甲级最佳射手（约 14 球 × 0.90 = 12.6）几乎无法接近顶级最佳射手（约 25 球）。系数因此接近装饰。审计脚本 `scripts/audit-award-distribution.ts` 会输出三个层级的实际获奖分布；如确认失衡，下一步引入赛程归一 `(30 / 联赛轮次) ^ 指数`，指数可调。

### 团队成就乘子

| 成就 | 金球 | 位置奖 |
| --- | --- | --- |
| 联赛冠军 | ×1.18 | ×1.06 |
| 前四 | ×1.08 | ×1.03 |
| 中游 | ×1.00 | ×1.00 |
| 后四 | ×0.94 | ×0.97 |
| 洲际杯冠军 | ×1.10 | — |
| 世界杯冠军 | ×1.15 | — |
| 联赛杯冠军 | ×1.05 | — |
| 超级杯冠军 | ×1.05 | — |
| 国内杯合计上限 | ×1.08 | — |

国内杯合计设上限，使双冠（1.1025）不超过洲际杯（1.10），保持洲际杯的含金量。

### 位置奖构成

```
positionAwardScore = positionQuality
                   × availabilityFactor    // 0.85 + 0.15 × 出勤分/100
                   × 层级系数
                   × 团队系数
                   × 样本门槛              // ≥1800 分钟 1.00 / ≥1200 0.95 / 否则 0.85
```

用 `positionQuality`（纯位置产出，层级中立）而非 `seasonScore`，避免与显式层级系数构成双重折扣。出勤以轻量因子进入，因为 `positionQuality` 本身不含出勤。

### 金球

`seasonScore` 含 10% 权重的联赛强度，与显式层级系数重复。评奖改用**层级中立分**：

```
tierNeutralScore = seasonScore + (100 - leagueStrength) × 0.10
```

这是精确还原（把 leagueStrength 代入 100），不改 `seasonScore` 本身，因此已归档赛季的 `performanceSnapshot` 继续有效。

### 金靴

```
金靴分 = 进球 × 层级系数
```

平局顺序统一为 **金靴分 → 原始进球 → 助攻 → 出场 → uuid**，与射手王卡片的进球→助攻→出场对齐。展示上顶级联赛显示 `22球`，低级别显示 `20球 · 甲级×0.90`，让玩家看得懂为什么 20 球能压过 22 球。

### 新星

保持简单可读：**层级中立分 × 新星层级系数 × 样本门槛**，U23，排除同赛季已获其他奖者。

刻意**不**加入"突破性"权重——那会让奖项难以解释（"为什么 78 分赢了 80 分"）。赛季间的进步改由风向卡作为**展示上下文**呈现（"上季 65 → 本季 78"），不进入评奖公式。叙事放在展示层，判断放在公式层。

### 最佳教练拆两个

- **冠军教头**：顶级联赛冠军队教练，始终展示。
- **最佳教练**：保留超额完成预期公式，但排除冠军队，避免同一人出现两次。

强队由此获得承认，同时不破坏"超额"这个概念本身。

## 新增奖项

`best_forward`（最佳前锋）、`best_midfielder`（最佳中场），与最佳后卫 / 最佳门将同构：限顶级联赛，按位置奖公式排序。

### 存档兼容

`save-schema.ts` 的奖项类型白名单扩展为接受 7 种类型。旧存档只有 5 种，仍然通过校验——新增是**加法**，不需要升 `SAVE_SCHEMA_VERSION`，现有存档不丢。

已归档赛季的旧奖项是在旧规则下算出的，属于历史记录，不回溯重算。

## 奖项风向面板

### 出现条件

顶级联赛已赛场次 ≥ `BUZZ_START_ROUND`（16 / 30）时出现，挂在球员中心顶部。每轮推进后更新。

### 内容

7 张卡对应 7 个引擎奖项。每卡最多 5 名候选，分 3 档。卡头显示「第 N 轮形势 · 剩余 M 轮」。

每名候选显示：姓名、位置、球队、**球队当前联赛排名**（明确标注非最终）、本季关键数据（按奖项不同）、已有生涯荣誉（如「2届金球」）。

**不显示**：buzz 分数、名次、任何可排序的数值。

### 热度公式

```
buzzScore = 0.50 × 层级中立赛季分
          + 0.30 × 近 5 场状态分     // clamp(45 + 平均影响 × 8, 0, 100)
          + 0.20 × 球队势头分        // 近 6 场积分 / 18 × 100
```

近 5 场状态复用 `buildRecentPlayerForm`，它本身只保留每名球员最近 5 场样本。状态分的换算沿用 `star-presence.ts` 里 `recentPriority` 的既有约定。

## 不做什么

- 不在奖项结果里引入随机或抽签。
- 不升 `SAVE_SCHEMA_VERSION`，不回溯重算已归档赛季的奖项。
- 不改 `seasonScore` 本身——球员页、生涯榜、转会身价、叙事扫描都在读它。
- 不动参赛版。
