# 评奖系统重设计（第一期：算法 + 奖项风向）

状态：算法与「奖项风向」面板已实施，经 3 种子 × 30 季端到端审计。范围仅限评奖算法与风向面板；球员中心整体重构留到第二期。

## 为什么要改

v4.62.0 的评奖在一次实测里暴露了三类问题：一个联赛杯 + 超级杯双冠王，五项个人奖加最佳教练无一入选，而射手王却出自该队。

1. **球队成就几乎不进个人奖。** 只有金球奖有团队乘子；最佳后卫 / 最佳门将 / 最佳新星 / 赛季综合表现 / 射手王全部是纯个人分。
2. **杯赛荣誉只认洲际杯。** `season-end.ts` 传给评奖的 `continentalCupWinners` 只有大陆杯 / 南方杯 / 东方杯，而这三个杯 `firstSeason: 5, interval: 6`，六年才一届。联赛杯和超级杯冠军对个人评分贡献为零。
3. **同一个"最佳"有三份互不一致的实现。** 射手王新闻与金靴奖用 `playerStats` + 严格 `>`（先到先得），赛季回顾的射手王卡片用 `playerStatsHistory` + 进球→助攻→出场。进球并列时三者必然分歧。
4. **层级口径互相矛盾。** `seasonScore` 里联赛强度只占 10% 权重、跨度 10 分（顶级 100 / 甲级 95 / 乙级 90），实际只值 1 分；金球再乘 ×0.90 / ×0.78 构成双重折扣；金靴完全无系数；最佳后卫 / 门将硬性锁死顶级联赛。同一个乙级球星被三套规则分别对待。
5. **最佳教练惩罚强队。** `expectedPos = round(16 × (1 - (expectation - 1) / 4))`，expectation = 5 的三支豪门 expectedPos = 0，夺冠超额值为 −1，数学上永远拿不到该奖。
6. **前锋和中场没有位置奖。** 只有最佳后卫 / 最佳门将，中场球员在评奖体系里没有任何位置路径。

## 不可预判如何做到（不加随机）

评审结论：**奖项本身保持 100% 确定性**，不引入任何抽签。理由：

- 产品契约要求叙事只解释模拟事实，不改写结果；评奖属于模拟结果。
- RNG 流是承重墙。杯赛阶段 1 给超级杯加 pots 分档后，一次洗牌变四次，整个赛季构建的随机流错位，20 个候选种子里没有一个还能满足开局断言，推荐种子被迫从 20260709 换到 20260722。在颁奖时插一次抽签会让这类审计全部作废。

不可预判由三个诚实机制叠加产生：

1. **热度公式与评奖公式不同。** 风向卡用 `buzz = 0.5×赛季分 + 0.3×近 5 场状态 + 0.2×球队近 6 场势头`；评奖用全季聚合 + 最终联赛排名。两者本就不是一回事。
2. **阈值带代替名次。** 相邻候选 buzz 分差超过 `BAND_WIDTH` 才另起一档，档内按球队名排序而非分数。卡片只显示「最被看好 / 有力竞争 / 黑马」三档，不显示任何数字与名次。这既诚实（他们确实接近），又消掉了"第一就是冠军"的读法。
3. **最大变数本来就未揭晓。** 金球乘子里权重最高的是最终联赛排名（冠军 ×1.18 / 前四 ×1.08 / 后四 ×0.94）。第 16 轮时排名仍可大洗牌——即使把真实评分原样贴出来也预测不了第 30 轮。

跑火车的情况不隐藏：唯一领跑者且与次席差距超过 `RUNAWAY_GAP` 时，卡头标记「一人领跑」。那种情况玩家本来也算得出来，藏它没有意义。

### 层级系数

| 层级 | 通用（速率型指标） | 金靴（原始计数） | 新星 |
| --- | --- | --- | --- |
| 顶级 | 1.00 | 1.00 | 1.00 |
| 甲级 | 0.90 | 0.75 | 0.95 |

通用系数只适用于**速率型**指标——位置产出、赛季评分都按场次推导，本身不存在赛程不对称。

## 金靴：赛程与联赛质量是两个独立旋钮

顶级 30 轮，甲级 / 乙级各 14 轮。按原始进球乘系数时，90 季审计（3 种子 × 30 季）实测**低级别获奖 0 次**——系数完全失效。

根因不是系数太小，是赛程：

| | 场均总进球 | 轮次 | 每轮进球 |
| --- | --- | --- | --- |
| 顶级射手王 | 30.9 | 30 | 1.03 |
| 甲 / 乙级射手王 | 17.6 | 14 | **1.26** |

原始进球差 1.76 倍，赛程比 2.14 倍。**折算成每轮，低级别射手反而高 22%**——原始进球测的是「谁踢的比赛多」，不是「谁更会进球」。10% 的折扣打不动 2.14 倍的结构性差距。

因此拆成两个旋钮：

```
金靴分 = 进球 × (30 / 联赛轮次) ^ 指数 × 联赛系数
         └──── 结构性修正，不含判断 ────┘   └─ 唯一的质量判断 ─┘
```

**指数固定 1.0。** 赛程长度不携带任何球员质量信息，不该决定奖项。这是公平修正，不是对低级别让步。

**系数为什么必须低于 0.90。** 审计发现 0.90 / 0.80 实测恰好是**层级中立值**——该设定下低级别拿到 52% 的金靴，几乎正好等于其 16/32 的球队占比。也就是说这个系数不是「略微偏向顶级」，而是「完全不偏向顶级」，精确抵消了低级别每轮多进 22% 的效率优势。想表达任何偏好，必须低于 0.90。

实测（3 种子 × 30 季）：

| L2 / L3 系数 | 低级别获奖率 | 乙级单独 | 种子间波动 |
| --- | --- | --- | --- |
| 0.90 / 0.80 | 52% | 11% | 37%–63% |
| 0.80 / 0.65 | 36% | 3.3% | 20%–43% |
| **0.75 / 0.58** | **29%** | **2.2%** | 17%–37% |
| 0.70 / 0.50 | 17% | 0% | 13%–20% |
| 0.65 / 0.45 | 10% | 0% | 7%–13% |

**选定 0.75 / 0.58**：顶级 71%、甲级约 27%、乙级约 2%（约 45 季一次——第三级联赛拿金靴该是传奇级事件，不是常态）。

**关键不变量。** 在测试过的全部系数下，获奖者的进球效率始终是**本联赛均值的 5.2–5.6 倍**，18 组数据几乎不动。调系数只改变「怪物来自哪个联赛」，不会让奖项退化成「弱联赛刷数据」。质量有硬下限——这正是敢把它做成可调旋钮的前提。

三个审计脚本可复现以上全部数字：

- `scripts/audit-award-distribution.ts` — 端到端七奖层级分布（读引擎实际颁出的奖）
- `scripts/audit-golden-boot-normalisation.ts` — 指数扫描（同一批赛季重选，只变公式）
- `scripts/audit-golden-boot-coefficient.ts` — 系数扫描 + 获奖者效率不变量

### 团队成就乘子

| 成就 | 金球 | 位置奖 |
| --- | --- | --- |
| 联赛冠军 | ×1.18 | ×1.06 |
| 前四 | ×1.08 | ×1.03 |
| 中游 | ×1.00 | ×1.00 |
| 后四 | ×0.94 | ×0.97 |
| 洲际杯冠军 | ×1.10 | — |
| 世界杯冠军 | ×1.15 | — |
| 联赛杯冠军 | ×1.05 | — |

国内杯合计设上限，使双冠（1.1025）不超过洲际杯（1.10），保持洲际杯的含金量。

### 位置奖构成

```
positionAwardScore = positionQuality
                   × availabilityFactor    // 0.85 + 0.15 × 出勤分/100
                   × 层级系数
                   × 团队系数
                   × 样本门槛              // ≥1800 分钟 1.00 / ≥1200 0.95 / 否则 0.85
```

用 `positionQuality`（纯位置产出，层级中立）而非 `seasonScore`，避免与显式层级系数构成双重折扣。出勤以轻量因子进入，因为 `positionQuality` 本身不含出勤。

### 金球

`seasonScore` 含 10% 权重的联赛强度，与显式层级系数重复。评奖改用**层级中立分**：

```
tierNeutralScore = seasonScore + (100 - leagueStrength) × 0.10
```

这是精确还原（把 leagueStrength 代入 100），不改 `seasonScore` 本身，因此已归档赛季的 `performanceSnapshot` 继续有效。

### 金靴公式与展示

```
金靴分 = 进球 × (30 / 联赛轮次) × 联赛系数
```

平局顺序统一为 **金靴分 → 原始进球 → 助攻 → 出场 → uuid**，与射手王卡片的进球→助攻→出场对齐。

展示上把完整算式写出来。赛程折算引入后，「玩家能自己复算的奖才可信」这条原则不是变松了而是变紧了——多了一步换算，不写出来就是在要求玩家相信一个黑箱：

- 顶级：`45球`（已在基准赛程、满权重，无需算式）
- 低级别：`16球/14轮 → 折算34.3球 × 0.75 = 25.7`

风向卡用同一套折算，但只显示到折算值（`16球/14轮 · 折算25.7`），完整算式留给奖项本身。折算值是公开的奖项算术，不是风向内部状态——玩家本来就能从球员中心排出射手榜，暴露它不泄露任何风向依赖的信息。

### 新星

保持简单可读：**层级中立分 × 新星层级系数 × 样本门槛**，U23，排除同赛季已获其他奖者。

刻意**不**加入"突破性"权重——那会让奖项难以解释（"为什么 78 分赢了 80 分"）。赛季间的进步改由风向卡作为**展示上下文**呈现（"上季 65 → 本季 78"），不进入评奖公式。叙事放在展示层，判断放在公式层。

### 最佳教练拆两个

- **冠军教头**：顶级联赛冠军队教练，始终展示。
- **最佳教练**：保留超额完成预期公式，但排除冠军队，避免同一人出现两次。

强队由此获得承认，同时不破坏"超额"这个概念本身。

## 新增奖项

`best_forward`（最佳前锋）、`best_midfielder`（最佳中场），与最佳后卫 / 最佳门将同构：限顶级联赛，按位置奖公式排序。

### 存档兼容

`save-schema.ts` 的奖项类型白名单扩展为接受 7 种类型。旧存档只有 5 种，仍然通过校验——新增是**加法**，不需要升 `SAVE_SCHEMA_VERSION`，现有存档不丢。

已归档赛季的旧奖项是在旧规则下算出的，属于历史记录，不回溯重算。

## 奖项风向面板

### 出现条件

顶级联赛已赛场次 ≥ `BUZZ_START_ROUND`（16 / 30）时出现，挂在球员中心顶部。每轮推进后更新。

### 内容

7 张卡对应 7 个引擎奖项。每卡最多 5 名候选，分 3 档。卡头显示「第 N 轮形势 · 剩余 M 轮」。

每名候选显示：姓名、位置、球队、**球队当前联赛排名**（明确标注非最终）、本季关键数据（按奖项不同）、已有生涯荣誉（如「2届金球」）。

**不显示**：buzz 分数、名次、任何可排序的数值。

### 热度公式

```
buzzScore = 0.50 × 层级中立赛季分
          + 0.30 × 近 5 场状态分     // clamp(45 + 平均影响 × 8, 0, 100)
          + 0.20 × 球队势头分        // 近 6 场积分 / 18 × 100
```

近 5 场状态复用 `buildRecentPlayerForm`，它本身只保留每名球员最近 5 场样本。状态分的换算沿用 `star-presence.ts` 里 `recentPriority` 的既有约定。

## 实测分布（3 种子 × 30 季 = 90 季，端到端）

读引擎实际颁出的奖项，不是事后重算。

| 奖项 | 顶级 | 甲级 | 乙级 | 低级别占比 |
| --- | --- | --- | --- | --- |
| 金球奖 | 90 | 0 | 0 | 0% |
| 金靴奖 | 64 | 24 | 2 | **29%** |
| 最佳前锋 | 90 | 0 | 0 | 0% |
| 最佳中场 | 90 | 0 | 0 | 0% |
| 最佳后卫 | 90 | 0 | 0 | 0% |
| 最佳门将 | 90 | 0 | 0 | 0% |
| 最佳新星 | 76 | 11 | 3 | **16%** |

- **金球奖 71% 出自冠军球队**（64/90）。国内杯乘子与团队系数确实起作用了——这正是最初「双冠王颗粒无收」要修的东西。
- **低级别两条通道都通**：金靴 29%、新星 16%。至少一个低级别获奖的赛季占 38%。
- **金球与四个位置奖 100% 顶级**。位置奖是刻意的（后卫 / 门将历来如此）。金球不是硬锁，但层级中立分 ×0.90 加上「低级别球队永远拿不到冠军 / 前四乘子」，实际差距约 1.31 倍，90 季无一例外。这符合「世界最佳球员在最高级别联赛踢球」的直觉，但如果后续希望金球也偶尔下沉，这是下一个要动的旋钮——不是本次范围。

### 逐例核对

低级别金靴获奖者全部核对过，确认每个人都确实比当年顶级最佳射手每轮更高产（`scripts/probe-golden-boot.ts`）：

| 赛季 | 获奖者 | 获奖线 | 当年顶级最佳 |
| --- | --- | --- | --- |
| S13 | 马岩（胶州港湾） | 16球/14轮 → 25.7（1.14/轮） | 23球（0.77/轮） |
| S17 | 李志伟（辽宁队） | 28球/14轮 → 45.0（2.00/轮） | 38球（1.27/轮） |
| S24 | 铃木裕也（近江鹰） | 22球/14轮 → 27.3（1.57/轮） | 27球（0.90/轮） |

没有一例是「弱联赛刷数据压过真射手」。

### 一处与本次改动无关的既有观察

顶级射手王场均 30.9 球（区间 15–52），即场均约 1.0 球——远高于现实足球的顶级射手（约 0.8）。这是模拟既有的进球模型特征，**不是本次改动引入的**：改动前的审计同样是均场 31.15 球。若要校准，属于比赛模拟层，不在评奖范围内。

## 不做什么

- 不在奖项结果里引入随机或抽签。
- 不升 `SAVE_SCHEMA_VERSION`，不回溯重算已归档赛季的奖项。
- 不改 `seasonScore` 本身——球员页、生涯榜、转会身价、叙事扫描都在读它。
- 不动参赛版。
