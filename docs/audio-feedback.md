# 声音与触觉反馈资产记录

当前版本不下载第三方音效，也不使用外部版权采样。短反馈和比赛声场由 Web Audio 即时合成；八段赛事主题音乐由仓库内的可追溯合成脚本生成，并随应用发布。

`src/feedback/feedback-sounds.ts` 使用浏览器 Web Audio API 在用户设备上即时合成短音乐、重大事件与界面反馈：

- 开始观察：两音上行提示。
- 直播进球：三音短促上行提示。
- 重大爆冷：低音冲击加一次回升。
- 故事升级：两音章节提示。
- 赛季结束：三音收束提示。
- 推进、切换、确认、焦点锁定/取消、命运干预和无效操作：低音量、短包络的语义反馈。

开始观察与赛季结束使用同一组原创音色延伸出的短音乐动机，长度分别约 1.8 秒和 2.8 秒。界面提示按语义逐项校准，常规提示峰值约为 -18～-24 dBFS，重大提示约为 -16～-17 dBFS；播放时会短暂平滑压低正在运行的赛事主题。常规数据页面不会自行启动背景音乐，列表、滚动、悬停和自动新闻也不会发声；用户已在杯赛页选择的赛事主题可以在同一赛季内继续跟随。

`scripts/generate-tournament-music.ts` 保留同一组四音主题的三段世界杯音乐：

- `world-cup-theme-v1.m4a`：世界杯赛事页循环主题，约 38 秒，约 507 KB。
- `world-cup-final-v1.m4a`：保留的世界杯决赛典礼主题，约 26 秒，约 339 KB；当前比赛直播不播放。
- `world-cup-champion-v1.m4a`：保留的夺冠典礼收束，约 15 秒，约 191 KB；当前比赛直播不播放。

同一生成器还提供五段赛事身份主题：

- `league-cup-theme-v1.m4a`：联赛杯的紧张推进与淘汰赛脉冲，约 25 秒，约 288 KB。
- `super-cup-theme-v1.m4a`：超级杯的典礼铜管与开阔和声，约 29 秒，约 332 KB。
- `mainland-cup-theme-v1.m4a`：大陆杯的厚重框鼓、五声音阶与沉稳旋律，约 28 秒，约 333 KB。
- `southern-cup-theme-v1.m4a`：南洲杯的切分鼓点、明亮拨奏与流动旋律，约 25 秒，约 294 KB。
- `eastern-cup-theme-v1.m4a`：东洲杯的克制鼓组、清透槌音与留白旋律，约 27 秒，约 313 KB。

地区主题表达的是游戏内虚构赛事身份，不复刻现实歌曲或民族录音。合成器只使用项目内定义的和声、铜管、簧片、拨弦、槌音、低音、鼓组与短体育场反射参数，不包含录音采样。已提交的 M4A 是正式运行资产；`pnpm music:generate` 是可追溯重建入口，目前需要 macOS 自带的 `afconvert`。`pnpm audio:check` 会核验八首清单、M4A 容器、10～45 秒时长、单曲与 2.8 MB 总体积上限。

杯赛页面只选择并控制本赛事主题；实际播放由 Layout 内的全局赛事音乐导演持有，因此推进或路由切换不会销毁音频。选择只保存在当前运行会话：同一赛季内可以跟随到总览和其他页面，赛季更替、重置游戏或手动关闭时清除，不写入存档。跟随离开所属赛事页后，新闻条下方显示一条 44px 播放状态栏；赛事页本身隐藏该状态栏，避免和标题区按钮重复。

打开任何比赛直播时，赛事页面主题都会在完整直播生命周期内暂歇，决赛和终场阶段也不会接管或启动主题音乐；关闭直播后，原赛事页面主题按会话状态渐入恢复。页面间的音乐身份切换使用约 320～360ms 的交叉淡化，任意时刻只保留一个权威音乐会话。全部八首合计约 2.54 MiB，按首次需要加载，PWA 首次安装不会预缓存；成功请求后由最多八项的独立运行时缓存保存。

`src/feedback/match-soundscape.ts` 在比赛直播中复用同一个手势解锁后的 `AudioContext`：

- 三层确定性滤波噪声构成看台底色，噪声缓冲在同一 `AudioContext` 内缓存复用。
- 声场宏观强度读取赛事级别、比赛分钟、比分差、暂停状态和点球阶段；演出层额外读取当前进攻方向、场地区域、进攻阶段、定位球和射门飞行状态。所有输入均为只读表现数据，不读取或改变模拟 RNG。
- Canvas 分别在定位球准备、皮球离脚和权威结果到达时发送一次性信号，声音不会因文字播报提前揭晓进球或扑救。
- 主队、客队与中立场进球分别使用强欢呼、短暂压低的客场反应和均衡反应。
- 射偏、门柱、普通拿稳、关键扑救、封堵、角球/任意球哨声、红黄牌、换人及半场、加时、点球、终场使用不同的合成反馈。
- 安静、均衡和球场三档分别调整总线、持续看台、即时反应、足球动作和进球重音；安静档压低环境声但保留关键触球，均衡档为默认，球场档突出现场氛围。
- 所有比赛只使用开球哨作为声场起点，不再播放焦点比赛或决赛开场音乐。进球重音属于短比赛事件音效，跟随“比赛与界面音效”音量，不读取“主题音乐”音量。
- 直播关闭后停止本场声场；若此前存在赛事页面主题，则交回全局音乐导演恢复。世界杯、联赛杯、超级杯和三项洲际杯决赛遵守同一规则。

普通界面反馈由 `UiFeedbackCue` 明确标注在关键行为上，不使用全局按钮点击拦截。每种提示独立限频，推进失败使用单独的短降调，所有 UI 提示都不会触发振动；重大爆冷和赛季结束仍是仅有的触觉事件。

这些波形、频率、时长、噪声种子和包络均为本项目原创参数。设置中的“比赛与界面音效”和“主题音乐”分别控制两条音量链；总声音开关仍可一次静音。关闭声音、页面隐藏或极低资源设备环境下不会调度音频；`prefers-reduced-motion` 只减少视觉动态和关闭可选触觉，不会替用户静音。缺少完整 Web Audio 能力时自动退回原有短提示音。触觉只用于重大爆冷和赛季结束，默认关闭，并在浏览器不支持 `navigator.vibrate` 时静默降级。
