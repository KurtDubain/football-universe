# 声音与触觉反馈资产记录

当前版本不包含外部音频文件，也不下载第三方音效。

`src/feedback/feedback-sounds.ts` 使用浏览器 Web Audio API 在用户设备上即时合成五组短提示音：

- 开始观察：两音上行提示。
- 直播进球：三音短促上行提示。
- 重大爆冷：低音冲击加一次回升。
- 故事升级：两音章节提示。
- 赛季结束：三音收束提示。

开始观察与赛季结束使用同一组原创音色延伸出的短音乐动机，长度分别约 1.8 秒和 2.8 秒；普通页面不循环背景音乐。

`src/feedback/match-soundscape.ts` 在比赛直播中复用同一个手势解锁后的 `AudioContext`：

- 三层确定性滤波噪声构成看台底色，噪声缓冲在同一 `AudioContext` 内缓存复用。
- 声场宏观强度读取赛事级别、比赛分钟、比分差、暂停状态和点球阶段；演出层额外读取当前进攻方向、场地区域、进攻阶段、定位球和射门飞行状态。所有输入均为只读表现数据，不读取或改变模拟 RNG。
- Canvas 分别在定位球准备、皮球离脚和权威结果到达时发送一次性信号，声音不会因文字播报提前揭晓进球或扑救。
- 主队、客队与中立场进球分别使用强欢呼、短暂压低的客场反应和均衡反应。
- 射偏、门柱、普通拿稳、关键扑救、封堵、角球/任意球哨声、红黄牌、换人及半场、加时、点球、终场使用不同的合成反馈。
- 安静、均衡和球场三档分别调整总线、看台、动作和音乐比例；安静档压低环境声但保留关键触球，均衡档为默认，球场档突出现场氛围。
- 焦点比赛与决赛开场使用约 1.7 秒的低音和弦动机；直播关闭后停止全部循环源。

这些波形、频率、时长、噪声种子和包络均为本项目原创参数。关闭声音、页面隐藏或极低资源设备环境下不会调度音频；`prefers-reduced-motion` 只减少视觉动态和关闭可选触觉，不会替用户静音。缺少完整 Web Audio 能力时自动退回原有短提示音。触觉只用于重大爆冷和赛季结束，默认关闭，并在浏览器不支持 `navigator.vibrate` 时静默降级。
