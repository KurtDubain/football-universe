# 声音与触觉反馈资产记录

当前版本不包含外部音频文件，也不下载第三方音效。

`src/feedback/feedback-sounds.ts` 使用浏览器 Web Audio API 在用户设备上即时合成五组短提示音：

- 开始观察：两音上行提示。
- 直播进球：三音短促上行提示。
- 重大爆冷：低音冲击加一次回升。
- 故事升级：两音章节提示。
- 赛季结束：三音收束提示。

这些波形、频率、时长和包络均为本项目原创参数，并在第一次实际反馈时按需加载。关闭声音、页面隐藏、`prefers-reduced-motion` 或极低资源设备环境下不会调度音频。触觉只用于重大爆冷和赛季结束，默认关闭，并在浏览器不支持 `navigator.vibrate` 时静默降级。
