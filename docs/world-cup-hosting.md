# 环球冠军杯东道主规则

## 届次与抽签

- 环球冠军杯在 `S4、S8、S12...` 举行，赛季开始时创建当届档案并公布东道主。
- 全部 32 支球队都具备承办资格。抽签不读取 `overall`、`reputation`、`tier` 或联赛级别。
- 优先选择历史承办次数较少的地区；存在多个地区时不连续选择上一届所在地区。
- 在选定地区内排除最近三届东道主后进行固定种子均匀抽签；候选不足时才允许复用。
- 抽签使用由宇宙种子和届次赛季派生的独立随机源，不消费比赛模拟 RNG。

## 场地与加成

- 世界杯小组赛和淘汰赛仍全部标记为中立场，名义上的 `homeTeamId` / `awayTeamId` 只用于比分与统计归属。
- 中立场不会应用普通 `HOME_ADVANTAGE`。
- 仅当东道主实际出现在世界杯 fixture 中时，东道主攻、中、守三项获得独立 `WORLD_CUP_HOST_ADVANTAGE`，当前为 4%。
- 预测、正式模拟、赛前因素和赛果都读取同一个 `tournamentHostTeamId`，不得按球队名称或 UI 状态推断。

## 历史与存储

- `worldCupEditions` 每届保存赛季、东道主、公布赛季、冠军、亚军和东道主最终成绩。
- 档案最多保留 50 届，约等于 200 个赛季；长期赛果与荣誉仍按各自原有上限保存。
- 当前比赛状态、赛历 fixture、赛果、荣誉和届次档案中的东道主必须一致，存档导入与世界数据审计会拒绝非法引用。

## 音乐边界

- 世界杯赛事页、决赛和夺冠分别使用按需加载的原创音轨。
- 音轨不进入首次 PWA 预缓存，播放后进入最多三项的独立运行时缓存。
- 音乐只属于表现层，不读取或改变种子、比赛结果、球员统计和赛季状态。
