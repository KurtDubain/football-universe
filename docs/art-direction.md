# Football Annual Art Direction

## Visual Thesis

《足球联赛宇宙》采用“东亚足球年鉴 × 现场转播台”的视觉语言：用赛季编号、
比分字形、编辑线、俱乐部色和纸张网点表现一个会持续几十年的足球世界。
它应当像一套长期积累的赛事档案，而不是通用后台、霓虹科幻界面或经理游戏。

## Core Grammar

- **Ink**: 页面以近黑墨色为底，层级靠明度、留白和线条建立，不靠大量阴影。
- **Paper**: 主文字使用偏暖白；奖杯与历史只使用克制黄铜色。
- **Pitch**: 绿色只表示行动、进行中状态和球场语义，不铺满所有界面。
- **Signal**: 红色只用于直播、危险和关键结果；球队色只用于球队身份。
- **Index**: 赛季、轮次、比分和版本使用窄体数字语法，中文标题保持清晰稳定。
- **Rules**: 赛事页像专刊，直播像转播信号，历史页像档案，数据页像统计版面。

## Image Policy

- 首屏只保留一张强主视觉，当前为平面丝网印刷式足球年鉴封面。
- 电影化体育图片仅用于开幕、决赛、夺冠和时代节点，不进入普通数据列表。
- 图片不承载球队名、比分、按钮或唯一信息；所有动态内容必须是实时 HTML 文本。
- 所有叙事图片统一由网格、裁切和暗色蒙版纳入转播版式，避免各自形成一套 UI。
- 禁止新增泛化的发光球体、蓝紫霓虹、玻璃卡片、巨大足球或无意义人物剪影。

## Interface Rules

- 首屏优先顺序：赛季状态 > 观察对象 > 本轮焦点 > 推进动作 > 次级数据。
- 可点击的卡片必须使用一个真实按钮或链接；锁定、收藏等次级动作必须是同级控件。
- 移动端球队长名优先显示短名，不以省略号隐藏身份。
- 卡片只用于独立重复对象、模态框和真正需要边界的工具；页面章节使用分隔线和版式。
- 任何常驻动效都必须表达直播、推进或数据变化；普通浏览不使用循环装饰动画。

## Review Checklist

1. 隐藏所有图片后，界面层级与操作仍然成立。
2. 关闭阴影后，版面仍然依靠对齐、字号和分隔线保持清晰。
3. 320px 宽度下没有页面级横向滚动，所有主要控件至少 44px。
4. 普通页面没有为了“高级感”新增无意义渐变、发光或嵌套卡片。
5. 新图片能够明确回答“这是哪个赛事时刻”，而不是只提供气氛。
